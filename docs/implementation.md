# 最初の動作版の実装メモ

2026-09-26。閲覧専用の開発版であり、要件定義の全受け入れ条件を満たした正式版ではない。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/main.rs` | 起動、保存ディレクトリ、デモと撮影オプション |
| `src/ui.rs` | eguiの3ペイン、設定、キーボード操作、画面状態 |
| `src/worker.rs` | バックグラウンドの処理キュー、資格情報ストア、UIへの結果通知 |
| `src/nntp.rs` | TLS／STARTTLS、認証、一覧・概要・本文の取得、キャンセル |
| `src/article.rs` | MIMEと日本語の解析、Message-IDによるスレッド構築 |
| `src/store.rs` | SQLiteのトランザクション、検索、本文キャッシュ、既読 |
| `src/model.rs` | データ構造、階層絞り込み、取得番号範囲の計算 |

GUIはRust内で扱えるegui/eframe 0.33系を仮採用。3ペインとmacOS優先は実装開始時の仮定で、ユーザーが最終決定したものではない。GUI方式や対応OSを変える場合も、通信・保存・記事解析を再利用できる構成にした。

通信と通常のDB処理は専用スレッドで直列に実行する。UIは要求番号により古い結果を捨て、画面移動に伴う古い本文の混入を防ぐ。実行中の通信はソケットのshutdownでキャンセルする。DNS解決はOSのAPIに依存し、キャンセル完了が遅れる場合がある。

SQLiteはWALとsynchronous=FULLを使用する。本文はサーバーとMessage-ID、記事概要はサーバー・グループ・記事番号で管理する。既読は本文とは別のテーブルに保存し、キャッシュ整理で消さない。ホスト・ポート・認証ユーザー・接続方式の変更は新しい接続先として保存し、以前のデータを残す。

プロトコル応答は複数行終端まで確認してから保存する。1行1MiB、概要・グループ応答32MiB、記事本文8MiB、MIME境界指定64個を上限とする。制限超過はエラーにし、不完全な受信を成功として保存しない。本文のMIME解析に失敗しても、受信が完了した元データは保持する。

## 検証結果

macOS / Rust 1.96.1 / 開発ビルドで確認。

自動テスト18件が成功（ライブラリ10件、統合テスト8件）。初回起動の設定画面とデモ記事の画面は `docs/images/` に実ウィンドウの撮影結果を保存した。

- ビルド、整形、Clippy（警告をエラー扱い）。
- 日本語4文字コード、MIME encoded-word、multipartのtext/plain選択、HTML・添付の非表示。
- 参照循環と欠落親、階層絞り込み、最新／新着／過去の取得範囲。
- 再オープン時の保存、クロスポストの既読、サーバー間の分離、本文削除後の既読保持、欠番、番号範囲の巻き戻り。
- localhostのソケットを使ったOVER→XOVER、dot-stuffing、途中切断、失効記事、Message-ID不一致、通信キャンセル。
- TLS／STARTTLS上の認証成功、未信頼証明書・ホスト名不一致の拒否、STARTTLS拒否時の降格防止、平文での認証防止。
- デモ記事を使った実ウィンドウの起動とPNG撮影。日本語・3ペイン・選択状態・既読表示を目視確認。

テストのTLS証明書は365日で失効するため、期限を超えた場合は `tests/fixtures/README.md` の手順で更新する。

### 保存・スレッド処理の測定

`cargo run --offline --example measure_cache` の単発測定。開発ビルド、10万グループと同一グループ10万記事概要、親子10万段の固定データ。描画やネットワークを含まない。

| 処理 | 測定値 |
| --- | --- |
| 10万グループの保存 | 1.02秒 |
| 10万記事概要の保存 | 1.71秒 |
| 10万グループの読み込み・未読集計 | 133ms |
| 10万記事概要の読み込み | 227ms |
| 10万記事のスレッド構築 | 73ms |

要件N-01〜N-03のGUI応答・起動時間・本文表示時間の合格を示す測定ではない。
